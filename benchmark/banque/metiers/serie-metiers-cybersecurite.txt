## Y01 Entropie d’un mot de passe
Catégorie : Calcul
Un mot de passe de 12 caractères est tiré au hasard parmi les lettres majuscules, minuscules et les chiffres. Combien de combinaisons possibles, et quelle entropie en bits ?
Attendu : 26 + 26 + 10 = 62 symboles ; 62^12 ≈ 3,2 × 10^21 combinaisons ; entropie = 12 × log2(62) ≈ 12 × 5,95 ≈ 71,5 bits.

## Y02 Hameçonnage
Catégorie : Rédaction
Explique en 5 lignes à un employé comment reconnaître un courriel d’hameçonnage et quoi faire s’il en reçoit un.
Attendu : adresse de l’expéditeur ou nom de domaine suspect ; ton urgent ou menaçant ; lien dont l’adresse réelle (survol) ne correspond pas ; pièce jointe inattendue ; demande de mot de passe, de code ou de paiement ; ne pas cliquer ni répondre, signaler au service informatique, et prévenir tout de suite si l’on a déjà cliqué ou saisi un mot de passe.

## Y03 Vérifier un mot de passe
Catégorie : Code
Écris une fonction Python verifier(mot_de_passe) qui renvoie la liste des règles non respectées : au moins 12 caractères, une majuscule, une minuscule, un chiffre et un caractère spécial. Donne deux exemples d’appel.
Attendu : fonction qui teste les cinq règles (len ≥ 12, any(c.isupper()), any(c.islower()), any(c.isdigit()), any(not c.isalnum())) et renvoie une liste de messages, vide si tout est respecté ; exemples cohérents (« Abc » échoue sur la longueur, le chiffre et le caractère spécial ; « Bonjour-Labe2026 » passe) ; pas de stockage du mot de passe en clair ; code exécutable.

## Y04 Code de connexion non demandé
Catégorie : Raisonnement
Un employé reçoit par SMS un code de double authentification pour sa messagerie alors qu’il n’a rien demandé. Que cela signifie-t-il et que doit-il faire ?
Attendu : quelqu’un connaît probablement son mot de passe et tente de se connecter ; ne jamais communiquer ni valider le code ; changer immédiatement le mot de passe (et partout où il est réutilisé) ; prévenir le service informatique ; vérifier les connexions et appareils récents ; une erreur de saisie d’un tiers est possible mais ne doit pas être supposée.

## YD3 Temps de cassage
Catégorie : Calcul
Document : doc-cybersecurite-audit.pdf
Recalcule le nombre de mots de passe possibles avec la politique actuelle et le temps nécessaire pour tous les essayer, avec la vitesse donnée dans le rapport.
Attendu : 8 chiffres : 10^8 = 100 millions de combinaisons (et non 1 milliard) ; à 10 milliards d’essais MD5 par seconde : 10^8 / 10^10 = 0,01 s, donc instantané et non « plusieurs années » ; la conclusion du rapport est fausse.

## YD4 Ordre des corrections
Catégorie : Raisonnement
Document : doc-cybersecurite-audit.pdf
Dans quel ordre faut-il corriger les vulnérabilités, et pourquoi ?
Attendu : d’abord V3 (RDP exposé sur Internet sans double authentification, 9,8, accès direct au réseau, fermer ou passer par un VPN avec double authentification, sans attendre les 30 jours) ; puis V1 (serveur web exposé, faille connue et exploitée, mettre à jour Apache) ; puis V2 (hachage des mots de passe avec bcrypt ou Argon2 et nouvelle politique) ; enfin V4 (renouveler le certificat) ; justification par l’exposition et le score.
