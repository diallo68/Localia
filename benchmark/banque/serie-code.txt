## P04 Corriger un bug
Catégorie : Code
Ce code doit compter les jours où l’humidité dépasse 90 %, mais il oublie le dernier jour. Corrige-le et explique l’erreur.
```python
def jours_humides(hr):
    n = 0
    for i in range(len(hr) - 1):
        if hr[i] > 90:
            n += 1
    return n
```
Attendu : range(len(hr)) (ou boucle directe sur hr) ; explication : range(len(hr) - 1) s’arrête avant le dernier élément. jours_humides([95, 80, 92]) == 2.
