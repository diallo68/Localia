## K2
Catégorie : Code
Cette fonction Python doit renvoyer la moyenne glissante. Trouve le bug, explique-le et corrige-le :

def moving_average(values, window):
    result = []
    for i in range(len(values) - window):
        result.append(sum(values[i:i + window]) / window)
    return result
Attendu : Décalage d'une unité : range(len(values) - window + 1). moving_average([1, 2, 3, 4], 2) doit donner [1.5, 2.5, 3.5]. Bonus : window <= 0 ou > len(values).
