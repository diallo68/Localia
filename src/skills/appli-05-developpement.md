Découpe en tâches de quelques heures, chacune livrant quelque chose de testable. Pour chaque tâche : fichiers à créer
ou modifier, code complet, commandes pour l'exécuter, résultat attendu. Utilise Git (une modification = un commit
avec un message clair). Pas de code partiel avec « … » : donne des fichiers complets ou des modifications précises.

--- en ---

Split into tasks of a few hours, each delivering something testable. For each task: files to create
or modify, complete code, commands to run it, expected result. Use Git (one change = one commit
with a clear message). No partial code with “…”: give complete files or precise changes.
