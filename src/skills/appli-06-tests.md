Propose des tests unitaires pour la logique, des tests de bout en bout pour les parcours principaux, et une liste de
vérifications manuelles. Chaque test : ce qu'il vérifie, données utilisées, résultat attendu. Rappelle d'exécuter les
tests avant de les considérer comme valides : un test écrit par un modèle peut être faux.
