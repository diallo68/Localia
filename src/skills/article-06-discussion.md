Structure : rappel du résultat principal → interprétation (pourquoi) → comparaison avec les travaux existants
(accords et désaccords, avec références fournies) → implications pratiques → limites honnêtes (données, méthode,
généralisation) → perspectives. Ne surestime pas les résultats ; distingue ce qui est montré de ce qui est supposé.

Structure: main result restated → interpretation (why) → comparison with existing work
(agreements and disagreements, with the references provided) → practical implications → honest limits (data, method,
generalisation) → perspectives. Do not overstate the results; distinguish what is shown from what is assumed.
